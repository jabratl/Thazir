- Extras with the same recipe (table rows only): Threads, Bluesky, TikTok web, LinkedIn, Tumblr, Quora, Twitch, Mastodon.
- Sensitive-media blur (P5): CSS/JS blur of images + videos on social sites, tap to reveal, per-site switch, blur strength. Two modes: (a) "Blur all media until tap" = always works; (b) "Use the site's own flag" = Reddit NSFW tag, X sensitive-media layer, etc. (flags change, can break).
- Home / speed dial tiles + pinned Android home-screen shortcut that opens the site in Social mode (P6).
- Unread number in the tab title "(3) ..." shown as a small badge on the tab (P7). Data saver: stop video autoplay, optional (P7).
- Separate login per site (own WebView profile) when the WebView supports multi-profile (P9, optional; code for private tabs already uses WebViewCompat.setProfile).

PARTLY (works, with limits)
- Discord: ONLY the web client (discord.com/app) with desktop UA + phone viewport (same trick as Messenger chat). Text chat OK. Voice needs mic permission (SitePerms) and may be flaky; screen share, push, overlay = no. hCaptcha at login is normal.
- WhatsApp Web / Telegram Web / Snapchat web: desktop-fit mode like Discord. WhatsApp Web needs the real WhatsApp on a phone to link ("link with phone number" code). Snapchat web is limited by Snapchat.
- Nudity detection by AI (P8a/P8b): possible only for IMAGES (thumbnails / posts), through a small on-device model that the USER must supply (model.tflite, I cannot download files in the planning sandbox). Not 100 % accurate (misses + false blur). Video frames / live video: NOT covered. Marked EXPERIMENTAL, last in the plan, can be dropped.
- "Continue with Google" login is often blocked inside any WebView by Google. Use email / password on those sites. We do NOT try to defeat Google's check.
- Facebook / Instagram / X may show a security check when they see a new device user agent (already noted for 0.0.224).

CANNOT (do not promise)
- Background push notifications, sound alerts, app badge on the launcher icon: a browser tab cannot receive them when closed. (Only the unread number while the tab is open, P7.)
- Real app features: stories camera effects, AR filters, calls with video, screen share, in-app payments.
- Anything that needs the official app's private API or logging in for the user.
- Guaranteed banner hiding: scripts match text / classes of live sites, they will need small fixes when the sites change. Each site profile has its own CSS/JS string so a fix = one-line patch.
