STATUS 0.0.480 = 0.0.479 + $popup filter rules (the biggest hole the owner found when comparing Thazir with Brave's adblock-rust: FilterList used to SKIP every rule that has the $popup option, and EasyList / uBlock filters have thousands of them = the ad pop-up / pop-under hosts). DONE: FilterList.T_POPUP = 256 (NOT part of T_ALL, so a normal rule never matches a pop-up check and a $popup rule never blocks a normal request); network() now maps option popup -> T_POPUP instead of skipping the rule (~popup is harmless); AdBlock.blocksPage(url, openerUrl, popup = false): with popup = true it also asks FilterList.verdict(..., T_POPUP) (an @@...$popup exception wins, a block makes the page blocked even when the host is not in the built-in host list); TabManager passes popup in shouldOverrideUrlLoading (tab.popup) and in onPageStarted of a pop-up tab (true). No new file, no native code, no new permission; the lists are parsed again at every app start (FilterList.load), so no re-download is needed. adblock-rust itself was judged NOT suitable now (Rust / NDK / JNI = new native crash risk, see the owner chat); only its ideas are used. Files: FilterList.kt, AdBlock.kt, TabManager.kt, app/build.gradle.kts, CHANGELOG_PREPEND_0_0_480.txt, HANDOFF.txt, HANDOFF+Thazir+0.0.480.txt, DELETE.txt, HANDOFF_INDEX.txt, CHANGELOG_ARCHIVE.txt. This zip also repeats the 0.0.479 files (MainActivity.kt, AppNag.kt) so it is complete even if 0.0.479 was never applied. RULES: T_POPUP must stay outside T_ALL; $popup is only checked for pop-up tabs (AdBlock.blocksPage popup = true), never for normal requests or normal tabs; the first-party skip in blocksPage (same site as the opener) stays. OPEN: still skipped on purpose: regex rules (ReDoS / speed risk), scriptlets +js (needs document-start script injection, crash risk), $redirect, $removeparam, $csp, $denyallow / $from / $to, #@# cosmetic exceptions, :has-text and other extended selectors; an @@ exception always beats a $important block (no $important priority); a pop-up that passes the lists but comes from a tap-hijack is still opened.
