0.0.430 (S5 BUILD: chrome.tabs + chrome.windows gaps)
- Why: installed extensions that call tabs.duplicate / move / goBack / goForward / zoom / highlight / discard / captureVisibleTab or windows.getAll / getLastFocused / remove got "Not supported in MGB" or an undefined function.
- How: new ExtApi2.kt (handlers named "ext.<api>", so ONLY installed extensions use them; the built-in Media Grabber is untouched). tabs.duplicate = TabManager.cloneTab (not selected). tabs.move = new TabManager.moveTab (pinned tabs stay first, tab.onMoved fires). goBack / goForward use the existing back / fwd. getZoom / setZoom = text size of the tab (1.0 = 100 %, 0 = site default, range 0.25-5, next page load resets it like per-tab zoom); getZoomSettings answers automatic / per-tab; setZoomSettings is accepted, not stored. tabs.highlight = switch to that tab. tabs.discard = same step as Suspend (refused for the tab on screen, Home, extension and private tabs, and non-http pages). captureVisibleTab = draws the WebView of the tab on screen (max 4096 px side, jpeg q 92 default or png, data URL max 14 MB), needs activeTab or a host permission of that page; refused on private / Home / non-http pages. windows.getAll / getLastFocused return Thazir's one window (id 1, populate supported, private tabs left out). windows.remove answers "Cannot close the only browser window." and closes nothing.
- Changed files: ExtApi2.kt (new), ExtApi.kt (1 register line + allow-list rows), TabsApi.kt (manager() accessor), TabManager.kt (moveTab, zoomOf, setZoomOf, discardTab), assets/shim/chrome-shim.js (real bridge methods for the new names, only when the extension is installed), app/build.gradle.kts.
- CHANGED BEHAVIOUR: those calls now work for installed extensions. Built-in Media Grabber: no change (checked by node: identical chrome member list when the "gaps" flag is off). Private tabs are invisible to the NEW calls (older calls tabs.get / tabs.query are unchanged, see COULD BREAK).
- COULD BREAK: zoom is text size, not page zoom (layout zoom of the page is not changed). captureVisibleTab uses WebView.draw: on some phones / WebView versions the picture can be blank or black (then the call still succeeds with that picture). tabs.onZoomChange never fires. Extensions that need windows.remove to really close a window get an error. KNOWN OLD ISSUE, NOT changed here: tabs.get / tabs.query (TabsApi) can still list private tabs to an extension (url / title hidden unless it may see them); fix is planned in S12 regression pass if you want it.
- NOT tested: Gradle build (CI), device. node checks of the shim passed. Kotlin only checked for brace / paren balance.
- DEVICE TEST (needed only): 1) Install a test extension that uses these calls, or use the self-test extension later (S11). Without one: open Report center > "Extension API gaps" after using any extension: it must show no tabs.duplicate / move / goBack / captureVisibleTab / windows.getAll lines. 2) Extension with a "screenshot" / "capture page" button (for example a full page screenshot extension): tap it on a normal https page: a picture of the page (not blank) arrives. On a private tab or the Home page: it must fail, no crash. 3) Media Grabber (built-in): popup, queue, one download = same as before.
- Rollback: delete ExtApi2.kt, remove the ExtApi2.register() line + the new names in the EXT_OK regex (ExtApi.kt), manager() (TabsApi.kt), moveTab / zoomOf / setZoomOf / discardTab (TabManager.kt), the "if (GAPS)" block inside the isExt part of chrome-shim.js.
