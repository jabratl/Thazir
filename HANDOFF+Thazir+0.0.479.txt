STATUS 0.0.479 = 0.0.478 + (1) Share / link from another app no longer opens a SECOND Thazir window; (2) ad hardening: ads can no longer push you into Chrome / other apps (owner report: a page opened Chrome by itself again and again, also when Thazir came back to the front, Brave does not do this). DONE: (1) MainActivity is launchMode standard, so a Share (ACTION_SEND) or a link from another app made a new MainActivity (new task, own tabs, no Incognito tab) and onNewIntent never ran. Now MainActivity.onCreate checks the live main window (companion mainRef, WeakReference, set in onCreate of a non-site window): if one is alive and the intent is not ACTION_MAIN and not a site window, the new instance (flag dup) hands the intent to the live window (onNewIntent), moves that task to the front (appTasks.moveToFront) and finishes at once; onDestroy of a dup returns first (it must not reset SiteWindow.mainUp); mainRef is cleared in onDestroy of the live window. Manifest NOT changed on purpose (launchMode singleTask would make Android ignore FLAG_ACTIVITY_NEW_DOCUMENT of the site windows, A7). (2) AppNag.blocksExternal(ctx, url, hasGesture, popup) (same switch as the social app block, pref app_nag_block, default ON): a NON-http(s) address (intent://, googlechrome://, market://, tel: ...) is refused when it comes without a tap, or from a pop-up tab (the pop-up tab is closed); even with a tap it is refused when it only pushes you to another browser (googlechrome / firefox / brave / opera / edge schemes, intent:// with a browser package, intent:// with http(s) data and no package). Before, only known social apps were blocked without a tap, everything else went to openExternal. Hook = TabManager.shouldOverrideUrlLoading just before openExternal (toast limited to once per 2.5 s, Diag line extblock). (3) TabManager.onCreateWindow: a tab that is not the active tab never opens a window (Diag \"popup refused (background tab)\").
