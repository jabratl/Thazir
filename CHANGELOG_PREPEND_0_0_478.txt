0.0.478 (NEW: Incognito like Chrome - name, icon, start page, no third-party cookies, nothing remembered on disk; handoff clean-up tool)
- Base = 0.0.477. Changed files: TabManager.kt, BrowserExtras.kt, SitePerms.kt, SiteSheet.kt, TextZoom.kt, PrivateTabs.kt, HomeView.kt, SettingsScreen.kt, SettingsIndex.kt, MenuCustom.kt, MainActivity.kt, MenuBar.kt, HubSheet.kt, CommandCenter.kt, TabSwitcher.kt, LinkInbox.kt, PrivNotify.kt, AppLock.kt, AppearanceScreen.kt, ExtListScreen.kt, HowToUse.kt, PasswordStore.kt, app/build.gradle.kts. NEW: res/drawable/ic_incognito.xml, tools/handoff_prune.py, HANDOFF_INDEX.txt, CHANGELOG_ARCHIVE.txt. No new permission, no new dependency.
- 1. NAME: "Private" is now "Incognito" everywhere the user reads it (New Incognito tab, Incognito tabs in the switcher, Settings > Privacy and security > Incognito tabs, the notification "Close all Incognito tabs", "Incognito tabs are locked", Allow in Incognito for extensions, How to use). New icon (hat + glasses). The saved key of the menu row is unchanged, so a customised menu keeps its order / hidden rows.
- 2. START PAGE of an Incognito tab: "You've gone Incognito" + a card: what is not saved, who can still see the activity, what stays on the phone (same facts Chrome lists).
- 3. THIRD-PARTY COOKIES are blocked in Incognito tabs (Settings > Privacy and security > Incognito tabs > "Block third-party cookies in Incognito", ON by default, applies at once to open Incognito tabs).
- 4. SITE PERMISSIONS: camera / microphone / location answers and the per-site sheet chips in an Incognito tab are kept in memory only (no row in Site permissions, nothing in mgb_perm) and forgotten when the last Incognito tab closes. Reading the normal saved answers still works (Chrome: Incognito starts with the normal site settings).
- 5. TEXT SIZE chosen in an Incognito tab is for that tab only (no site name saved in mgb_zoom).
- 6. AUTOFILL: the Incognito WebView is hidden from the phone's autofill service (nothing typed there is offered for saving).
- 7. START-UP WIPE: Incognito cookies / cache left by an app that was killed are deleted when the app starts (before: at the next Incognito tab).
- 8. HANDOFF CLEAN-UP: tools/handoff_prune.py + DELETE.txt in this zip. The old HANDOFF+Thazir+<ver>.txt (13 MB), plan files and CHANGELOG_PREPEND files are removed; HANDOFF_INDEX.txt keeps one line per removed handoff, CHANGELOG_ARCHIVE.txt keeps the text of every removed changelog note, git history keeps the full files.
- COULD BREAK: (1) a site that needs a third-party cookie (embedded login, some video / payment frames) may fail in Incognito: turn the switch OFF. (2) Someone who ticked "Remember" for a permission in an Incognito tab is asked again next time (intended). (3) Hub / menu / Command Center labels changed: nothing that searched for the old English word "Private" in the UI is kept, "private" still finds the Incognito rows in Command Center and Settings search.
- NOT tested: Gradle build (CI), device. Written without a Kotlin compiler; brackets counted (balanced). If CI shows an error: HomeView.kt (Incognito card), BrowserExtras.kt (ask with priv), TextZoom.kt (dialog), MainActivity.kt (MenuSheet.Item key =).
