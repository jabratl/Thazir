0.0.457 (MODIFY: Hub style bar is less crowded - the "+" button is hidden until turned on. Address bar redesign step S2)
- Base = 0.0.456. Changed: AppearancePrefs.kt, AppearanceScreen.kt, app/build.gradle.kts. No new file, no new permission, no new pref key.
- 1) With Appearance > Hub button ON, the "+" next to the address bar is hidden (New tab and Private tab are Hub tiles). It shows again when the owner turns "New tab button" ON by hand while the Hub button is ON. Hub OFF = exactly as before (default ON).
- HOW: AppearancePrefs.newTabBtn(c) = if (hubOn && key ap_bar_newtab was never set) false else the saved value (default true). Its only two callers (MainActivity.refreshShield and the Appearance "New tab button" row) follow it, so the row shows OFF and the bar hides the "+" together; AppearanceScreen.onChange already calls refreshShield, so it is live. The row hint says it.
- 2) WIDTH CHECK (no code needed): the Hub button (44 dp) replaces the Home-action button (44 dp, hidden), so the bar is as wide as before MINUS the "+" (34 dp). At 360 dp: 360 - 20 margin - 8 padding = 332; Hub 44 + tab ring 34 + menu 40 + field margins 8 = 126 -> the address field gets about 206 dp (>= 140 dp shield rule). Both arrows ON: 206 - 72 = 134 dp, handled by the existing navTight() (< 400 dp: smaller arrows, no engine badge, minWidth 96 dp). Back / Forward arrows still follow ap_nav_back / ap_nav_fwd / ap_nav_hide, unchanged.
- CHANGED BEHAVIOUR: only with the Hub button ON and the New tab button never touched: no "+". Everyone else: nothing changes.
- COULD BREAK: an owner who toggled "New tab button" before (key exists) and then turns the Hub ON keeps the "+" (their saved value wins); a Reset (Settings > general) does not clear ap_bar_newtab, so the "+" follows the saved value afterwards.
- NOT tested: Gradle build (CI), device. Only a Kotlin bracket check. DEVICE TEST: 1) Hub ON (fresh): no "+" on the bar, Appearance row "New tab button" = OFF. 2) turn that row ON: the "+" shows, tap = new tab, hold = private tab. 3) Hub OFF: "+" back as before. 4) both arrows ON at 360 dp: field >= 96 dp, no overlap, no engine badge. 5) type in the field: "+" hides as before. 6) light + dark.
