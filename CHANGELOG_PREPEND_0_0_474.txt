0.0.474 (MODIFY: drop a tab on a tab = group at once, also in the Private view; NEW: Pin group)
- Base = 0.0.473. Changed files: app/build.gradle.kts, TabSwitcher.kt, HowToUse.kt. No new file, no new resource (the pin uses the existing ic_pin), no new permission, no new dependency.
1. DROP A TAB ON A TAB: this already worked since 0.0.297 (hold a card, drag it onto another tab), but it opened a "New tab group" dialog (name + colour). Now the group is made AT ONCE: the name is the first free "Group N" (new freeGroupName()), the colour is nextColor(), and the usual Undo bar comes from moveInto ("2 tabs added to Group N"). Rename / recolour later in the group menu (Edit group name / Edit group colour). Dropping on an existing group card = add to it, as before. Dropping inside an open group = reorder, as before.
2. DRAG IN THE PRIVATE VIEW: canDrag() now also allows mode 1 (Private). Private tabs can be dragged onto another private tab or onto a private group card (the cards were already drop targets there, only the gate was closed). A group still holds only private or only normal tabs (kindOf).
3. PIN GROUP / UNPIN GROUP (group menu: long press a group card, the 3-dot of a group row, or the 3-dot inside an open group). Pinned groups: sit FIRST in the tab grid and on the Groups page (groupNames()), show a small pin (card next to the tab count, row next to the name, open-group title), and ask "<name> is pinned. Close / Delete it anyway?" before Close group / Delete group. Saved with the session: the groups JSON keeps "v": 2 and gets one new key "p" (names of pinned groups), so an older build ignores it and keeps the groups (rollback is safe). The pin follows the group through Edit group name, and comes back with Undo (GroupSnap.pinned, closeAnimated, doCloseList, ungroup, pullOut, Delete group).
4. HowToUse.kt: one new step in "Browse and tabs" (drag onto a tab, Pin group).
- COULD BREAK: (1) anyone who liked the naming dialog now gets "Group N" and has to rename in the menu (there is no switch to bring the dialog back). (2) Long press + drag in the Private view: same gesture code as the normal view (dragTouch), check that a private card still opens its menu on a short hold. (3) A pinned group is only "first and guarded": it is not sticky in any other way (Close all in the grid never touches grouped tabs anyway). (4) GroupStrip.kt (bottom strip) does not show the pin.
- NOT tested: Gradle build (CI), device. Written without a Kotlin compiler: if CI shows an error, it is in TabSwitcher.kt near a line marked "// 0.0.474".

(3) Drag a tab onto an existing group card: added, as before. (4) Private view: drag a private tab onto another private tab: private group. Short hold still opens the tab menu. (5) Group menu > Pin group: pin icon on the card / row, the group moves before the unpinned ones in the grid and on the Groups page, the open group title shows the pin; Unpin group reverses it.
