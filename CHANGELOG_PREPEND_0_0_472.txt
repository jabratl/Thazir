0.0.472 (Bookmarks / History / Downloads: flat rows with hairline dividers, round icons, filled search box)
- Base = 0.0.471. Changed files: app/build.gradle.kts, BmUi.kt, BookmarksScreen.kt, DownloadsScreen.kt. No new file, no new resource, no new permission.
1. BmUi.kt: NEW flatRow(a, on, insetStartDp) + flatParams(). A flat full-width row: ripple (mg_primary, alpha 0x30), transparent fill (selected = mg_surface blended 16% with mg_primary, same tint as before), and a hairline divider (mg_outline, half a dp thick) at the bottom that starts insetStartDp from the left so it lines up with the text. folderTile is now round (radius 18 on a 36 dp tile). rippleCard / cardParams / card are UNCHANGED (still used by PwScreen, Manage start page, the sort / 3-dot popups).
2. BookmarksScreen.kt: bookmark / history rows and folder rows use flatRow + flatParams instead of rippleCard + cardParams (no card margin, no outline); row padding 16 dp, min height 58 dp; divider inset 68 dp (66 for a folder row, 104 in select mode because of the check circle). Site icon (favTile) is round and 38 dp (was a 10 dp rounded square, 34 dp). Search box = filled round box without outline (same look as the Downloads search).
3. DownloadsScreen.kt: card() is now a flat row (padding 16 / 12 / 12 / 12, flatRow divider inset 16, no margins); the icon tile is round (radius 20 on 40 dp); a selected file row uses flatRow(on = true). Pause / Resume / Cancel / Show / Open buttons stay inside the row as before.
4. The pill bar (BookmarksScreen.pills) is NOT changed: it is still ONE function shared by the three screens, so the three screens stay in step. All colours come from R.color.mg_* (light + values-night), no new hex values.

Ripple on a transparent row relies on the white mask in flatRow (RippleDrawable with a ColorDrawable mask), min SDK 24 is fine (LayerDrawable layer gravity / height / inset need API 23).
