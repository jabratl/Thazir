0.0.436 (S11 BUILD: compatibility self-test extension + Report center)
- Why: a one-tap proof of which chrome.* functions Thazir supports on THIS phone, with a copyable list, so no more guessing.
- How: new ExtSelfTest.kt + assets/selftest/ (manifest.json + background.js, 3 KB). Settings > Extensions > "Compatibility self-test": Thazir adds a small temporary extension "Thazir Self-Test (temporary)" through the normal ExtRegistry path (new ExtRegistry.installAsset), its background calls 23 supported functions once (storage local / session / sync, runtime, alarms, contextMenus, notifications, tabs / windows query, cookies, downloads, declarativeNetRequest dynamic rule, action badge, i18n, commands, permissions, scripting list, webNavigation / offscreen / search / browsingData existence) plus 4 CSS facts of this WebView (nesting, @layer, color-mix, matchMedia), writes the result to its storage, Thazir reads it (max 20 s) and ALWAYS removes the extension + its storage + its gap rows (ExtGaps.forget) afterwards. A dialog shows: "Self-test: N pass, M fail, K not supported (WebView x)" + one line per test (PASS / FAIL: reason / NOT SUPPORTED). Same list in Report center > "Extension self-test" (WARN when something failed). Nothing is called that opens a tab, shows a notification, or deletes data.
- Own fixed id (from the name), so your installed extensions and their storage are never touched. No private tab involved. Close button; closing the dialog does not stop the run (result still goes to the Report center).
- Changed files: app/build.gradle.kts, app/src/main/java/com/jabra/mgb/{ExtSelfTest.kt (new), ExtRegistry.kt (installAsset + copyAssetDir), ExtGaps.kt (forget), DiagReport.kt (+1 section), SettingsScreen.kt (+1 row), HowToUse.kt}, app/src/main/assets/selftest/{manifest.json, background.js} (new), CHANGELOG_PREPEND_0_0_436.txt, HANDOFF_Thazir_EXT_PLAN_0.0.436.txt
- CHANGED BEHAVIOUR: nothing unless you tap the new row. New row + new report section only.
- COULD BREAK: if the phone kills the hidden background WebView (battery saver) the test ends with "no answer from the test extension" after 20 s (no harm, the extension is removed). If the app is killed in the middle, the temporary extension can stay in the list: remove it by hand (Settings > Extensions > Thazir Self-Test > Remove).
- NOT covered (left out on purpose, plan leftovers): content script + popup UI checks, tab based calls (scripting.executeScript, tabs.create, captureVisibleTab), ports, externally_connectable page test.
