0.0.432 (S7 BUILD: manifest fidelity A - include / exclude globs, options_ui open_in_tab, incognito not_allowed, action default_title)
- Why: installed extensions ignored a few manifest keys that Chrome honours (include_globs / exclude_globs, options_ui.open_in_tab, incognito, action.default_title).
- How: (1) content_scripts include_globs / exclude_globs: checked inside the injected script after "matches" (new pure helper ExtManifest.globRx: * = any text, ? = one character, everything else literal; a bad / empty / over-long glob is ignored with a log line, max 50). An extension WITHOUT these keys gets exactly the same script text as before. (2) options_ui.open_in_tab = true: Settings > Extensions > Options, the tray fallback and chrome.runtime.openOptionsPage open the page in a TAB; false / options_page keeps the extension window (as before). (3) manifest "incognito": "not_allowed": its content scripts are not injected in PRIVATE tabs (ContentInjector.attach gets a priv flag; the entry list is filtered; refresh keeps the flag). "spanning" / "split" / no key = old behaviour (still runs in private tabs). (4) action.default_title (also __MSG_ text) is the tray / button title until the extension calls action.setTitle.
- Checked, nothing to change: css of content_scripts is injected before the JS of the same entry (document start); run_at, all_frames, exclude_matches, match_about_blank, match_origin_as_fallback were already complete; web_accessible_resources already exists since 0.0.108 (EngineHost.extPublic). Manifest v2 / MV2 background pages: not applicable, ExtSafety refuses every manifest v2 extension.
- Changed files: ExtManifest.kt (new), ContentInjector.kt, ExtRegistry.kt (Info: optionsInTab, actionTitle), ExtApi.kt (title), ExtListScreen.kt / ExtTray.kt / ChromeBridge.kt (open options), TabManager.kt (1 line: attach(..., priv)), HowToUse.kt, app/build.gradle.kts.
- CHANGED BEHAVIOUR: an extension with incognito "not_allowed" stops running in private tabs. An extension with options_ui.open_in_tab true opens its options in a tab. A tray title now shows action.default_title when the manifest has one.
- COULD BREAK: an extension whose include_globs use a pattern style Chrome does not (regex between slashes): such a glob is treated as plain text and never matches (script does not run). Glob match is on the full address (case sensitive).
- NOT tested: Gradle build (CI), device. node tests passed (glob matching, escaping, no-key = no change). Kotlin only checked for brace / paren balance.
- DEVICE TEST: see 0.0.433 entry (one list for S7 + S8).
